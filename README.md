# Vinayak G Raju — portfolio

Personal site, built as plain HTML, CSS and JavaScript with no build step, and served by GitHub Pages.

## Files

- `index.html` — all page content. Edit text here.
- `styles.css` — colors (top of file), type and layout. Dark mode follows the visitor's system setting.
- `ransac.js` — the live RANSAC demo in the hero.
- `favicon.svg` — browser tab icon.

## Updating the site

Edit a file on GitHub (or locally and push to `main`). GitHub Pages republishes within a minute or two.

To preview locally:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```
